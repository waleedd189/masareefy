> متابعة لـ `docs/mezanetak-analysis.md` (المصفوفة 38 بند) و`docs/mezanetak-backlog.csv`.
> الحالة محدّثة بعد تنفيذ الدفعة الأولى على فرع `arena/6cef6377-masareefy` (PR #2).

| | العدد |
|---|---|

## 5) ما رفضناه عمدًا من Mezanetak

| الصلاحية/الميزة | السبب |
|---|---|
| `com.google.android.gms.permission.AD_ID` + `ADSERVICES_*` + `BIND_GET_INSTALL_REFERRER_SERVICE` | تتبّع إعلاني — مالوش لازمة في تطبيق مالي شخصي |
| `ACCESS_FINE_LOCATION` / `ACCESS_COARSE_LOCATION` | الموقع مش مطلوب لحساب المصروفات |
| `pairip` + `CHECK_LICENSE` (حماية ترخيص Play) | DRM بيقفل التشغيل خارج المتجر |
| `safe_device` (كشف root) | بيمنع مستخدمين شرعيين من غير فائدة أمنية حقيقية لتطبيق ويب |
